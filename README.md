```text

│   ├── constellation.js              # Royal Cobalt & Sapphire Particle Canvas Engine
│   ├── Collaboration.js              # Project Showcase Registry & Modal Logic
│   └── main.js                       # Core UI Interactivity
└── Appscript/
    ├── code.gs                       # Google Sheets Ingestion & Dual Gmail Dispatcher
    ├── ReceivedEmailMark.html        # Admin Lead Alert Template (-> kbjintapa23@gmail.com)
    └── SendEmailLead.html            # Client Auto-Responder Template (24-48h SLA + Copy of Answers)
```

### **How the Contact Automation Works:**
1. **Form Submission**: Prospect submits project scope in the Contact section.
2. **Database Sync**: `Appscript/code.gs` parses the payload and appends a timestamped record to the `Inquiries` tab in Google Sheets.
3. **Instant Admin Alert (`ReceivedEmailMark.html`)**: Dispatches a formatted HTML summary with all prospect answers and 1-click reply buttons to `kbjintapa23@gmail.com`.
4. **Instant Client Confirmation (`SendEmailLead.html`)**: Sends a personalized confirmation email from **Kent Brian Jintapa (AI Automation Specialist & GHL Expert)** with a copy of their submission and a **24–48 business hours** response commitment.
